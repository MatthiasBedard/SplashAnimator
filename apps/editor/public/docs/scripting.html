Write and preview a frame script

  1. Right-click a frame cell or its position on the timeline ruler and choose Script…. You can also use Control → Edit current frame source… on the scene.
  2. Enter TypeScript directly as a frame body. Try the example below. Type timeline. or press Ctrl+Space for suggestions. Hover over a name to see its type.
  3. Frame edits stay in a draft while you type. They attach to the frame when you leave the code editor, switch tabs, or close it. Press Ctrl+S (Cmd+S on macOS) to apply them immediately. A new script opened from the timeline starts with // Code goes here. and appears in Project Explorer immediately. Use Check TypeScript for diagnostics, and save the project to keep its frame scripts on disk.
  4. Project TypeScript files stay as drafts when you switch tabs or leave the code editor. Click Save file or press Ctrl+S (Cmd+S on macOS) to write the active file to the project folder.
  5. In the browser editor, choose Control → Preview saved scripts…. Prepare the preview and step through it to inspect the timeline, state, and resulting artwork.

An S in a timeline frame cell marks attached source. The Frame scripts section in Project Explorer lists attached scripts. On the scene, symbol scripts are grouped by symbol name. In Open scripts, use the arrow keys to move between tabs, Enter to open the focused tab, and Delete to close it. 

const visits = typeof state.visits === "number" ? state.visits : 0;
state.visits = visits + 1;
timeline.stop();

This counts visits to the scripted frame and stops playback there. The first frame is 0 in code and 1 in the editor. Use an authored frame label when you want a jump to keep working after the timing changes.

Frame scripts execute in explicit script previews and interactive HTML. Checking source, ordinary timeline playback, Test Movie, and ordinary exports do not execute them. The bounded runtime has no direct access to browser APIs, the network, or the filesystem.

Symbol frame scripts are attached to a symbol’s local frame. When working in the isolated symbol timeline, edits save to the draft when you leave the code editor. Apply the symbol timeline to keep them. Use Inspect local timeline scripts where available, or enable Run placed symbol frame scripts in the browser scene preview for eligible placements.

Download interactive HTML

In a built editor, open Control → Preview saved scripts… and choose Download interactive script HTML. Open the downloaded file in a browser, then choose Play scripts, Step script, or enter a JSON object and choose Send JSON. The file includes its artwork and script runtime and can open offline. Interactive HTML supports saved main-timeline scripts using timeline, runtime, state, and JSON input. Use the editor's script previews for stage mutations, text, sound, or nested script execution.

Timeline, runtime, state, and input

timeline.currentFrame, timeline.totalFrames, timeline.fps, timeline.playing
Read the zero-based frame, frame count, frames per second, or playback state of this script’s timeline.
timeline.play(), timeline.stop()
Resume or pause playback.
timeline.gotoAndPlay(frame), timeline.gotoAndStop(frame)
Jump to a zero-based integer frame index or an exact label on this timeline. An out-of-range index or unknown label raises a script error.
runtime.random()
Return a seeded number from 0 inclusive to 1 exclusive. Restoring a checkpoint resumes the same sequence.
state
Store values between dispatches in the current script session. Values can be strings, finite numbers, booleans, null, arrays, or objects built from those values. Use your own keys, such as state.visits. Reset the preview to start a fresh session.
input
Read values delivered to the current dispatch. The preview can send JSON or captured keyboard and pointer input. A qualifying button release can provide input.buttonActivation. Check whether optional values are present before using them.
input.textInput
An optional text edit with binding, value, selectionStart, selectionEnd, and selectionDirection.

Stage and instances

stage can be undefined. Use optional chaining for lookups or guard it before making changes. Stage changes affect the preview, while the authored project stays as saved. 

if (stage) {
  const pose = stage.getTransform("player");
  if (pose) {
    stage.setTransform("player", { ...pose, x: pose.x + 12 });
  }
}

Name the placed graphic player in the editor before trying this example. Use a layer ID to disambiguate duplicate instance names.

stage.width, stage.height, stage.layerCount
Read stage dimensions and layer count.
getInstance(name, layerId?) → SplashPlacement | undefined
Find an authored instance exposed on the current frame.
getTransform(name, layerId?), setTransform(name, transform, layerId?)
Read or change the absolute position and rotation of an eligible named graphic. Supply finite x and y coordinates and a rotation in degrees.
getBasis(name, layerId?), setBasis(name, basis, layerId?)
Read or change local scale, shear, or reflection before rotation. The basis tuple [a, b, c, d] maps (x, y) to (a*x + c*y, b*x + d*y). Identity is [1, 0, 0, 1].
setVisible(name, visible, layerId?)
Set preview visibility on an eligible graphic or button exposure without changing its playback.
getChildInstance(parentName, name, layerId?), setChildVisible(parentName, name, visible, layerId?)
Find or change the visibility of an exposed named graphic or button child of an eligible parent.
spawnGraphic(name, symbolId, position)
Place a captured static graphic by symbol ID under a preview-owned name. Use the library methods below to place items by link name instead.
getSpawned(name), removeSpawned(name)
Read a spawned item’s position and source ID, or remove it from the preview.

Library links

Use an item’s authored Link Name as the lookup key. A link is separate from the item’s display name or an instance name on the stage.

stage.library.get(link) → SplashLibraryItem | undefined
Get metadata for a symbol, bitmap, or audio item. Check kind before using kind-specific properties.
stage.library.spawnGraphic(link, name, position)
Place an eligible linked symbol using its authored playback default.
stage.library.spawnBitmap(link, name, position)
Place an eligible linked bitmap at its natural size. Both spawn methods take a preview-owned name and an { x, y, rotation } position. 
const library = stage?.library;
const item = library?.get("logo");
if (library && item?.kind === "bitmap" && item.canSpawn) {
  library.spawnBitmap("logo", "previewLogo", { x: 40, y: 24, rotation: 0 });
}

Dynamic text

splashText.set(binding, content)
Write a string to a dynamic text binding in the current scope.
splashText.setForInstance(instanceName, binding, content)
Write a string to a text binding on an eligible named instance.

For a dynamic text field with the binding score, call splashText.set("score", "100").

Scripted sound

Use stage?.sound in a preview with Enable scripted sound selected and linked PCM16 WAV audio available.

play(link, offsetSamples?, gain?)
Replace the current voice with the linked WAV. The optional offset is in zero-based samples.
stop(), pause(), resume()
Stop the voice, freeze its logical sample position, or resume it.
seekSamples(offsetSamples), positionSamples()
Seek while preserving the paused state or read the current logical sample position. The position can be undefined when no voice is active.

For a WAV with the link click, call stage?.sound?.play("click").

Types and scope

The scripting API provides objects to a frame body. Its TypeScript interfaces describe those objects and are available as type annotations. Use the supplied objects directly. The API exposes no constructors for these interfaces.

SplashTimeline, SplashState, SplashValue, SplashInput, SplashInputValue, SplashTextInput
Playback, persistent session data, and delivered input. Input values are read-only.
SplashStage, SplashPlacement, SplashPlacementTransform, SplashPlacementBasis
Stage capabilities and placement data. A placement includes id, name, layerId, symbolId, visible, and optional parentId.
SplashLibrary, SplashLibraryItem
Library operations and metadata. All items have link, id, and name. Symbols and bitmaps add width, height, and canSpawn. Symbols provide defaultPlayback and optional timed. Audio provides format, sampleRate, channels, and frames.
SplashDynamicText
Methods for updating authored text bindings in a preview.

Project Explorer files are stored separately from frame source. A frame script cannot import those files. IntelliSense lists API members and types; enter your project’s instance names, frame labels, link names, and bindings yourself.
